# ecomPay test shop

A pretend shop for trying the ecomPay card checkout in test mode. No real money moves.

Open the page, enter the ecomPay server address in the Gateway box (or open it with `?api=https://your-server`), add something to the basket and pay with a test card. The page asks the server for the real payment status and lets you refund test payments.

Test cards: 4200 0000 0000 0000 (approved), 4111 1111 1111 1111 (declined), 4918 1900 0000 0002 (3D Secure challenge). Any future expiry and any 3 digits.
